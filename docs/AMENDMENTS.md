| B10 | Baseline runs and the budget (review 3) | Baselines run in the same counted run as the model (same command, same run id), not separately. Baselines are offline and cost nothing, so they never consume a run on their own. |

If the 3 counted runs are used up by aborted runs, the verdict of record is still the first completed run; if none completed, the gate is reported as NOT EVALUABLE rather than guessed. |
